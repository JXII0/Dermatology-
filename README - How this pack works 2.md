# README: How this pack works

Start at [[Papulosquamous Lesions]].

**Source:** WAQF Dermatology 2nd edition. Page numbers are the printed ones. Written in original words. A supervising doctor must check every clinical detail before this is shared.

**➕** marks anything that is not in the book.

**Note types (colored squares in the titles):** 🟪 hub · 🟦 theory · 🟩 practical · 🟨 exam

**Callout colors:**
- green `success`: core card and take-home
- blue `info`: definition
- orange `warning`: pitfall
- red `danger`: red flag or worst type
- purple `tip`: mnemonic

**Properties and Base:** each disease note starts with a properties block. In Obsidian use **New base**, filter on group papulosquamous, and choose the columns.

**Exam echo:** R1 means the first round exam, R2 means the second rotation exam. Question numbers refer to those papers.

**Flashcards:** lines with `::` work with the Spaced Repetition plugin. Without the plugin, cover the right side and test yourself.

**Grey dots in the graph:** links to notes that are not written yet, or notes you already have in your own vault (for example Psoriasis).

**How to add this to your vault:** copy these files into your Derm vault. If Obsidian asks to replace a file, keep yours unless you want mine.
